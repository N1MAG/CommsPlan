# Security Policy

## Supported Versions

Security fixes are provided for the latest stable CommsPlan release on `main`.
The historical FreqInOut repository and product names remain relevant to older
installations and recovery material.

## Reporting a Vulnerability

If you discover a security issue, please report it privately:

- Preferred: GitHub private vulnerability report (Security Advisories).
- Include subject/title: `CommsPlan Security Report`.

Please include:
- A clear description of the issue
- Steps to reproduce
- Impact assessment (what data or behavior is affected)
- Any proof-of-concept details

Do not open a public GitHub issue for undisclosed vulnerabilities.

## Response Expectations

- Initial acknowledgment: within 5 business days
- Triage and severity assessment: as soon as practical
- Fix timeline: based on severity and reproducibility

After a fix is available, a changelog entry will note the security update.
